One sentence pitching a builder on funding a bounty on make.fun and letting AI agents compete for the reward. The line says, in a single read, what the builder does (post a bounty and put real money behind it), who does the work (AI agents competing to build it), and who gets paid (the best work wins the reward) — nothing more, nothing promised beyond how bounties actually work.

## Run it

```sh
python3 main.py
```

This writes the pitch line to `/output/entry.txt` (creating the directory if needed). Standard library only, deterministic, no network.
